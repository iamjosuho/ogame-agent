# 06｜閒置死羊收割（Inactive Farming / Raiding）

> 研究日期：2026-08-27（CST）  
> 適用基準：**OGame 13.0.0 / 13.0.0-r14**。專用於安全獲取外部資源的死羊收割機制。

---

## 1. 核心概念與標籤

在 OGame 中，長期未登入的玩家會被系統標記為閒置玩家（俗稱「死羊」）：
- **`(i)`（白羊 / 7 天閒置）**：7 天以上未登入。
- **`(I)`（灰羊 / 28 天閒置）**：28 天以上未登入，隨時可能被系統刪除或清理。
- **`(v)`（假期模式）**：不可攻擊或間諜偵測。
- **`(a)` / `(s)`（管理員 / 強保護）**：不可攻擊。

死羊的優點：其礦山會持續生產資源，但通常無人上線管理。若目標**完全無防禦與防禦艦隊**，則可以極低風險獲得可觀資源。

---

## 2. 完整收割 SOP 流程

```
[銀河系掃描 (Galaxy View)] 
  └─ 尋找母星周邊 ±5 太陽系內的 (i) / (I) 星球
       │
       ▼
[間諜探測 (Espionage)]
  └─ 發送 1–2 艘間諜探測機 (Probe) 取得最新報告 (需 Espionage Tech ≥ 2)
       │
       ▼
[報告過濾與安全審核]
  ├─ ❌ 有任何防禦 (Rocket Launcher, Laser 等 > 0) → 標記【跳過/放棄】
  ├─ ❌ 有任何駐留艦隊 (Fleet > 0) → 標記【跳過/放棄】
  ├─ ❌ 目標已脫離 (i) 狀態 (恢復活躍) → 標記【移出清單】
  └─ ✅ 0 防禦 + 0 艦隊 + 資源 > 門檻 → 進入出征計算
       │
       ▼
[艦隊出征 (Attack Mission)]
  ├─ 計算 50% 掠奪量 (Loot = (Metal + Crystal + Deut) / 2)
  ├─ 計算所需運輸船數量 (Small Cargo: 容量 5,000 / Large Cargo: 容量 25,000)
  ├─ 檢查當日攻擊次數 (≤ 6 次，遵守 Bashing Rule)
  └─ 發動 Attack 任務 (配合人類行為隨機延遲)
```

---

## 3. 艦隊配置與掠奪量計算

1. **掠奪上限**：
   - 標準宇宙對閒置/一般目標單次攻擊最多掠奪 **50%** 的當前庫存資源（部分特殊職業如 Discoverer/Bandit 依宇宙設定可能更高）。
2. **所需運輸艦公式**：
   - $\text{總掠奪量} = \lfloor \frac{\text{金屬} + \text{水晶} + \text{重氫}}{2} \rfloor$
   - $\text{所需小型運輸艦 (SC)} = \lceil \frac{\text{總掠奪量}}{5,000} \rceil$
   - $\text{所需大型運輸艦 (LC)} = \lceil \frac{\text{總掠奪量}}{25,000} \rceil$
3. **出征最低門檻（ROI 護欄）**：
   - 預估掠奪資源總量 $\ge 5,000$ 總資源。
   - 掠奪重氫價值須顯著高於來回飛行消耗（燃料消耗需 $< 15\%$ 總獲利）。

---

## 4. 紅線與安全護欄

1. **零防禦原則（Zero-Defense Rule）**：
   - 只要間諜報告顯示防禦設施（如導彈發射器、雷射砲、高斯砲等）$\ge 1$，一律**嚴禁攻擊**，避免運輸艦損毀。
2. **零艦隊原則（Zero-Fleet Rule）**：
   - 只要目標駐留任何戰鬥艦或民用船隻 $\ge 1$，一律**嚴禁攻擊**（除非僅有 Solar Satellite 且無防禦，但仍需謹慎）。
3. **報告時效性（Freshness）**：
   - 間諜報告時效超過 **2 小時** 者，出征前必須重新間諜偵測確認。
4. **防刷分/騷擾規則（Bashing Rule）**：
   - 同一顆星球在 **24 小時內出擊次數嚴格 $\le 6$ 次**（包含可能失敗的攻擊），避免觸犯遊戲規則封號。
5. **槽位保護（Fleet Slot Reservation）**：
   - 永遠保留至少 **1 個 Fleet Slot** 用於緊急 Fleetsave 或日常運輸，不把所有槽位塞滿打羊。

## 5. 目標資料庫維護（`runtime/memory/farm_targets.md`）

每輪巡邏時維護死羊清單：
- 座標（Coordinates）
- 玩家名稱與狀態（`(i)` 或 `(I)`）
- 最近間諜時間
- 防禦狀態（0 防 / 有防）
- 可掠奪資源估計
- 今日攻擊次數（0~6）
