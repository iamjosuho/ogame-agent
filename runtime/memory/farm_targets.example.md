## 🛡️ 紅線與安全護欄落實檢核

1. **零防禦原則 (Zero-Defense Rule)**：
   - 出征前必須間諜報告確認無火箭發射器、雷射砲等防禦工事（Defense = 0）。
2. **零艦隊原則 (Zero-Fleet Rule)**：
   - 出征前必須間諜報告確認無任何戰鬥艦船或駐留艦隊（Fleet = 0）。
3. **無攻擊次數限制 (Unlimited Inactive Raids)**：
   - 官方規則不限制 (i)/(I) 閒置死羊收割；單純依資源是否足夠（掠奪量 $\ge 5\text{k}$）即派艦收割。
4. **槽位保留 (Fleet Slot Reservation)**：
   - 出擊時永遠保留至少 1 個可用 Slot 以應對緊急避難（Fleetsave）。
